Extension for MPSKit.jl that adds infinite MPS/MPO types with non-trivial boundary conditions.

MPSKitPeriodic.FQHTranslator — Type
FQHTranslator <: AbstractTranslator

Translator for Fractional Quantum Hall states on a cylinder. Translates quantum numbers (sectors) across unit cell boundaries.

In the Landau gauge on a cylinder, translating by shift unit cells shifts the momentum quantum number by: ΔP = shift * Lcell * Nparticles where L_cell (norbitals) is the number of orbitals in the unit cell, and N_particles is the particle number charge.

MPSKitPeriodic.InfinitePeriodicEnvironments — Type
InfinitePeriodicEnvironments <: AbstractMPSEnvironments

Environments for an infinite MPS-MPO-MPS combination. These solve the corresponding fixedpoint equations:

\[GLs[i] * T_LL[i] = λ GLs[i + 1] T_RR[i] * GRs[i] = λ GRs[i - 1]\]

where T_LL and T_RR are the (regularized) transfer matrix operators on a give site for AL-O-AL and AR-O-AR respectively.

MPSKitPeriodic.InfinitePeriodicMPS — Type
InfinitePeriodicMPS{A<:GenericMPSTensor,B<:MPSBondTensor} <: AbtractMPS

Type that represents an infinite Matrix Product State.

Fields

  • AL – left-gauged MPS tensors
  • AR – right-gauged MPS tensors
  • AC – center-gauged MPS tensors
  • C – gauge tensors

Notes

By convention, we have that:

  • AL[i] * C[i] = AC[i] = C[i-1] * AR[i]
  • AL[i]' * AL[i] = 1
  • AR[i] * AR[i]' = 1
